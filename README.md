# 海盜大戰觸手 Tentacle Panic

一款復古 16-bit 像素風格的網頁打地鼠遊戲。你是海盜船長，要敲打從船邊漩渦冒出的章魚觸手，保護船不被拍沉，最後擊敗章魚王！

所有像素圖、音效與配樂都由程式即時產生，不需要任何外部圖檔或音檔。

## 如何遊玩

用瀏覽器直接打開 `index.html` 即可，不需要安裝任何東西。

> 中文像素字型（DotGothic16）由 Google Fonts 載入，需要連網。離線時會改用系統字型，遊戲仍可正常遊玩。

### 規則

- 點擊或觸碰冒出海面的**觸手**來敲打它。
- **不要打到美人魚！** 會扣 15 分並損傷船。
- 漏掉的觸手會拍打船身，船的耐久度（愛心）歸零就沉船。
- 在時間內達到目標分數就過關。
- 連續命中可累積連擊：5 連擊 ×2、10 連擊 ×3、15 連擊 ×4 得分。
- 打錯位置或漏掉觸手，連擊會歸零。

### 操作

| 動作 | 滑鼠 / 觸控 | 鍵盤 |
|---|---|---|
| 敲打漩渦 | 點擊觸手 | `Q W E` / `A S D` / `Z X C`（或數字鍵盤 `7 8 9` / `4 5 6` / `1 2 3`） |
| 敲打章魚王的眼睛 | 點擊眼睛 | `空白鍵` |
| 暫停 / 繼續 | 右上角 `II` 按鈕 | `Esc` 或 `P` |
| 地圖選關 | 點擊島嶼（再點一次出航） | `←` `→` 選擇、`Enter` 出航 |

| 關卡 | 名稱 | 場景 | 目標 | 時間 |
|---|---|---|---|---|
| 1 | 平靜海灣 | 白天 | 150 分 | 40 秒 |
| 2 | 珊瑚淺灘 | 午後 | 250 分 | 45 秒 |
| 3 | 夕陽海峽 | 黃昏 | 350 分 | 45 秒 |
| 4 | 月夜迷霧 | 夜晚 | 500 分 | 50 秒 |
| 5 | 章魚王的巢穴 | 暴風雨 | 擊敗章魚王 | 100 秒 |

### 章魚王戰

- 每打中一隻觸手，章魚王扣 1 點血量。
- 打中 6 隻觸手後章魚王會**暈眩**，眼睛出現閃爍的瞄準圈，這時敲牠的眼睛每下扣 4 點血量（每次暈眩最多 5 下）。
- 章魚王會瞇眼蓄力，然後噴出**墨汁**遮住部分畫面。
- 擊敗章魚王後進入**通關畫面**：船長站在金幣山上拔刀高舉，身後是「台北順起來」。網址加上 `?ending` 可直接觀看。

### 星級評分

過關得 1 顆星，另外：

- 船的耐久度剩一半以上：+1 顆星
- 一般關卡分數達目標的 1.5 倍／章魚王戰剩餘 30 秒以上：+1 顆星

進度、最高分與星數會存在瀏覽器的 localStorage。

```

├── index.html      畫面結構（標題、地圖、HUD、暫停、結算、通關）
├── css/style.css   像素風格介面
└── js/

```

## 技術說明

- **純 HTML5 Canvas + JavaScript**，沒有使用框架或建置工具。
- 遊戲內部解析度為 **320×180**，依視窗大小放大，並以 `image-rendering: pixelated` 保持像素銳利。
- 像素圖以字串陣列定義（每個字元代表一個像素），天空與海洋用 Bayer 抖色做出 16-bit 漸層。
- 音效與音樂使用 **Web Audio API** 即時合成方波、三角波與雜訊。配樂改編自傳統水手歌〈What Shall We Do with the Drunken Sailor〉。
- 支援滑鼠、觸控與鍵盤，介面可切換繁體中文與英文。

## 調整與開發

- **調整難度**：修改 `js/data.js` 最上方的 `LEVELS`，可調整時間、目標分數、船的耐久度、觸手出現間隔、停留時間、同時數量與美人魚出現機率。
- **直接進入指定關卡**：在網址後面加上 `?level=N`，例如 `index.html?level=5`。
- **重置進度**：在瀏覽器開發者工具的主控台執行 `localStorage.removeItem('tentacle-panic-v1')`。
